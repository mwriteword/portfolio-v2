## Hello!

This is the repo for my Content Design portfolio (https://vjtlaq.vercel.app). I built the initial designs in Replit, pushed the code manually through the native shell to this repo, made refinements using Claude Code, then linked the repo to Vercel for deployment.

I know enough about git and working in respositories to make simple text and string changes myself, but a majority of the building was done in Claude Code.
